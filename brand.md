# Brand — Kaido

_Status: active (derived from existing product palette)_

Kaido is a belief-curve trading venue: call the number, press conviction, fade the crowd. Visual language reads as a dark trading terminal with warm gold accents — not generic crypto purple, not cream editorial.

## Palette

| Token | Hex | Role |
|-------|-----|------|
| Ink | `#0b0b0c` | Page background |
| Surface | `#0a0a0b` | Cards, panels |
| Paper | `#f3efe6` | Primary text, CTA fill |
| Muted | `rgba(255,255,255,0.45)` | Secondary copy |
| Gold | `#d8c69a` | Accent, curves, focus ring |
| Up | `oklch(0.72 0.17 150)` | Bullish edge, positive PnL |
| Down | `oklch(0.63 0.21 25)` | Bearish edge, loss |

## Typography

| Role | Face | Usage |
|------|------|-------|
| Display | Instrument Serif | Market questions, section titles |
| Body | Geist Sans | Descriptions, helper copy |
| Data | JetBrains Mono | Prices, countdowns, vitals |

## Voice

- Active, trader-facing: "Place belief", "Your call", "Crowd target"
- Never expose μ, σ, Gaussian, scalar, trajectory in the default path
- Pair upside with downside on every ticket
- Label estimates honestly: "Estimated at current crowd"

## Signature

The payoff zone — user curve overlaid on crowd curve, widening and tightening with conviction. This is the product; the UI should teach it by interaction.
